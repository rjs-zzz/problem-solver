# 예시 0 — 입력 점검이 어떻게 보이는가 (표준 규모)

> 실행 전에 스킬이 무엇을 확인하고, 그 결과가 보고서에 어떻게 남는지 보여주는 형태 예시다.
> 조직·수치는 가상이다.

---

## 1. 사용자 요청

> problem-solver로 검토해줘. 민원 콜센터를 계속 직영할지 외주로 돌릴지 정해야 해.
> 직영은 상담사 8명, 외주 견적은 2곳에서 받았어. (견적서 첨부)

## 2. 스킬의 첫 응답 — 계획 고지 + 빠진 입력 안내

```
○ 규모 판정: 표준 — 신규 예산이 수반되나 계약 단위로 되돌릴 수 있음(부분가역)
○ 계획: 00 문제 재정의 → 01 구조화 → 02 진단(창조형, 약식) → 03 대안(직영 유지 /
  전면 외주 / 혼합 / Do Nothing) → 04 가중 평가 → 05 보고(5~10매) → 06 5인 패널 1라운드
○ 완료 조건: ① 권고안 1개 + 기각 사유서 ② 가정 목록 ③ Go/No-Go 조건

○ 입력 점검
  - 확보: 문제 진술, 선택지 2개, 외주 견적 2건
  - 빠진 것 (있으면 정확도가 오릅니다)
    · 성공 기준 — 비용 절감이 우선인지, 응대 품질이 우선인지
      → 없으면 "품질 유지 전제의 비용 절감"으로 가정합니다. 이 가정이 바뀌면 권고안이 바뀔 수 있습니다.
    · 직영 인건비·운영비 실적 — 없으면 비용 비교는 범위 추정에 그칩니다.
    · 바꿀 수 없는 제약 — 정원, 단체협약의 외주 관련 조항 등
  ※ 개인정보·대외비는 가리고 올려 주세요.

이대로 진행할까요? "그대로 진행"이라고 하시면 가정으로 채우고 바로 실행합니다.
```

## 3. 사용자 답

> 성공 기준은 응대 품질이 먼저야. 인건비 자료는 지금 없어. 그대로 진행해.

## 4. 보고서 첫 장에 남는 기록

```
## 【 민원 콜센터 운영 방식 검토 결과 보고 】

### Ⅰ. 보고 개요
○ 결론: (권고안 1문장)
○ 건의사항: (결재권자 결정 요청)
○ 결정 성격: 부분가역 — 계약 기간(2년) 동안은 복귀 비용 발생
○ 입력 현황: 준비도 부분 | 확보: 문제·선택지·외주 견적 2건·성공 기준 |
  가정: A1 직영 운영비(범위 추정), A2 단체협약에 외주 제한 조항 없음 | 미확보: 직영 비용 실적
○ 결론이 달라지는 입력
  1) 직영 운영비 실적 — 추정 범위 상단이면 외주 우위, 하단이면 혼합안 우위
  2) 단체협약 외주 조항(A2) — 제한 조항이 있으면 전면 외주안 탈락
  3) 성공 기준의 품질 가중치 — 30% 아래로 내리면 순위 역전
```

---

## 읽는 법

- 스킬은 **[필수]가 빠졌을 때만** 멈춰서 묻는다. 위 사례는 [필수]가 모두 있어 묻지 않고,
  표준 규모라서 [권장] 결손을 한 번 안내했다. 약식이면 안내 없이 바로 실행한다.
- 자료가 없다고 금액을 지어내지 않는다 — 범위 추정이나 등급 판정으로 내려간다.
- "결론이 달라지는 입력" 3줄이 사후 검토의 출발점이다. 그 값이 확인되면 그 부분만 다시 돌리면 된다.
