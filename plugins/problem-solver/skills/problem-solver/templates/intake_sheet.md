# 입력 양식 (사용자가 준비물·입력 양식을 물으면 아래 「양식」을 그대로 출력)

SKILL.md 「입력 점검표」의 사용자용 버전이다. 사용자가 채워서 붙여넣으면
Phase A 질문 없이 바로 실행한다. 빈칸은 비워둬도 된다 — (필수) 항목만 있으면
진행하고, 나머지는 [가정]으로 채운 뒤 보고서 첫 장 「입력 현황」에 표시한다.

## 양식

```
[문제 해결 요청]
1. (필수) 문제 — 무엇이 문제이고 무엇을 결정해야 하나:
2. (필수*) 비교할 선택지 — 각 안의 내용:        *선택·가부 판단을 요청할 때만
3. 성공 기준 — 무엇이 되면 해결인가:
4. 제약 — 예산 상한 / 인력 / 기한 / 바꿀 수 없는 규정:
5. 근거 자료 — 첨부하는 실적·견적·규정·회의록:
6. 결정 기한, 되돌릴 수 있는 결정인지:
7. 보고 대상과 분량 — 약식(1~3매) / 표준(5~10매) / 정식(15매 이내):

[조직 프로필]   ← 한 번 써 두고 재사용
- 조직 유형: (예: 공공기관 / 지자체 / 민간기업 / 병원 / 학교 / 개인)
- 상급·감독 기관:
- 자주 걸리는 법령·규정:
- 평가·감사 체계: (예: 경영평가, 감사, 이사회 보고)
- 승인 경로: (예: 부서장 전결 → 경영진 → 이사회)
- 주요 이해관계자:
- 예산 주기·고정 일정:

※ 개인정보·대외비는 가리고 올려 주세요.
```

## 항목별 영향 (양식 아래에 함께 안내)

- **3 성공 기준**: 평가 가중치의 기점이다. 바뀌면 권고안 순위가 바뀔 수 있다.
- **4 제약**: 대안이 탈락하는 이유가 된다. 없으면 모든 대안을 실행 가능하다고 가정한다.
- **5 근거 자료**: 있으면 금액·B/C까지 계산한다. 없으면 등급 판정만 한다 (금액을 지어내지 않는다).
- **6 기한·가역성**: 규모(약식/표준/정식)와 비판적 검토 강도를 정한다.
- **조직 프로필**: 승인 경로·이해관계자·법령 점검에 쓴다. 없으면 일반 조직 기준이다.

## 처리 규칙

- 양식을 채워 온 요청은 [필수]가 있는 한 다시 묻지 않는다. 빈칸은 「입력 점검표」의 '없을 때' 처리를 따른다.
- 양식 없이 문장으로만 온 요청도 같은 항목을 문면에서 먼저 찾아 채운다.
