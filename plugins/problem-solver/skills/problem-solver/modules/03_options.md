# Module 03: 대안 도출 (Option Generation)

## 목적
확정된 원인(또는 창조형 문제의 목표)에 대해
실행 가능한 복수 대안을 설계한다.
선택지 없는 보고는 보고가 아니라 통보다.

## 주력 방법론
- Working Backwards (베이조스 — Amazon 주주서한;
  Bryar & Carr, Working Backwards, 2021):
  성공한 미래 시점의 결과물을 먼저 쓰고 현재로 역산.
  00의 '성공 기준'을 미래 결과물의 골격으로 사용

## 예비 방법론
- 벤치마킹 매트릭스: 유사 문제를 해결한 국내외 기관 사례 수집 →
  자기 조직 조건과의 적합도 대조. 사례 이식이 아니라 원리 추출이 목적

## 실행 절차
1. **미래 결과물 작성**: 해결 성공 시점의 성과 요약문 (개조식 5~10줄)
   — 성공 기준 충족 상태를 구체 기술
2. **미니 프리모템 (즉시)**: 미래 결과물 작성 직후
   "이 미래가 오지 않을 이유 3가지"를 병기 — 낙관 편향 차단
   (06의 정식 Pre-mortem과 별개의 경량 장치)
3. **역산 분해**: 미래 결과물 달성에 필요한 조치를 시간 역순으로
   도출 (들여쓰기 개조식)
4. **대안 설계**:
   - 기본: 서로 다른 전략 경로의 대안 2~4개
     · '강도 차이'(소극/중간/적극)보다 '경로 차이'
       (내재화/외주/제도개선 등)로 구분 우선
   - 정형·소규모 문제: "단일안 + Do Nothing" 2개 구성 허용
   - 각 대안: 개요 / 핵심 조치 / 소요 자원(인력·자본·기술·시간·정보) /
     전제조건 / 관련 규정·승인 경로
   - **통제 등급 표기** (핵심 조치별 — 실행 주체의 재량 범위):
     · [자체] 주무부서 재량 / [내부승인] 경영진·이사회 결재 /
       [외부] 상급기관·법령 개정·타 기관 의사결정 의존
     · 핵심 조치가 [외부]뿐인 대안은 단독 대안으로 세우지 않는다 —
       외부 결정 전까지 가동할 [자체]·[내부승인] 조치를 병행 편성
     · [외부] 조치는 "건의·협의 추진"으로 표기하고, 성사 여부를
       [가정 An]으로 등록 (성사를 전제로 효과를 산정하지 않음)
5. **벤치마킹 보강**: 대안별 유사 사례 1개 이상 탐색
   - 사례 부재 시 '선례 없음' 명시 (이것도 정보다)
6. **Do Nothing 옵션 필수 포함**: 아무것도 하지 않을 때의
   비용·리스크 명시 — 대안 비교의 기준선

## 벤치마킹 근거 신뢰성 규칙 (필수)
1. 근거 위계 준수 (마스터 공통 규칙):
   [1급] 로컬 자료 > [2급] 정부·공공 원문 > [3급] 학술·검증 보도 >
   [4급] 보도자료·홍보물 (단독 근거 금지)
2. **로컬 자료 적극 요청**: 벤치마킹 착수 시 "이 사안과 관련해
   보유하신 내부 자료(공문, 회의록, 실적, 타 기관 입수 자료 등)가
   있으면 업로드해 주세요"를 능동 요청. 확보 시 웹 검색보다 우선 활용
3. **교차 검색 의무**: 성공 사례 수집 시 비판·한계·실패 보도를
   반드시 병행 검색. 성공 보도만 존재하는 사례는 '검증 불충분' 태깅
4. **오염 징후 체크** → 발견 시 근거 등급 강등:
   - 출처가 당사자 홍보물뿐인 경우
   - 수치의 원출처가 불명확한 경우
   - 발표 시점과 성과 시점이 근접한 경우 (성과 조기 발표)

## 산출물 (개조식)
## 【대안 설계서】
### 1. 미래 결과물 (Working Backwards 기점) + 미니 프리모템 3가지
### 2. 역산 조치 경로 (들여쓰기 개조식)
### 3. 대안 목록 (대안 A/B/C + Do Nothing)
  ○ 대안별: 개요 - 핵심 조치 - 소요 자원 - 전제조건 - 근거 사례(등급 표기)
### 4. 대안 간 차별점 요약

## 조직 맥락 체크포인트
- 각 대안의 승인 경로 명시: 부서장 전결 / 경영진 결재 /
  이사회 의결 / 상급기관 협의 — 경로가 다르면 실행 난이도가 다름
- 예산 수반 대안: 재원 유형(자체/외부지원/기금) 및 편성 시기 병기
- 노무·인사 관련 대안: 단체협약·취업규칙 저촉 여부 선확인
- 벤치마킹 우선순위: 동일 업종·유사 규모 조직 → 인접 업종 →
  일반 사례 순 (소속 업종에 맞게 순서 조정)

## 금지 사항
- 사용자가 처음 가져온 해결책을 무비판적으로 대안 1번에 넣지 말 것
  (포함하되 동등하게 검증)
- 구색 맞추기용 허수 대안(straw man) 생성 금지 —
  모든 대안은 실제 선택 가능해야 함
- 소요 자원 추정 근거 없이 "가능하다"고 쓰지 말 것
- 통제 범위 밖 조치([외부])를 자체 실행 가능한 것처럼 서술하지 말 것
