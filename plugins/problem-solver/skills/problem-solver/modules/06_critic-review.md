# Module 06: 비판적 검토 v2 (Critic Panel Review)

## 목적
최종 결론 확정 직전, 권고안을 **독립 관점의 반대자 패널**로 공격하여
결함을 사전 노출한다. 자동 실행 (confirm 없음).
검토의 목적은 부결이 아니라 '결재 방어력 강화'이며,
동시에 '더 나은 제3의 길'의 마지막 탐색 기회다.

## 핵심 설계 원칙 (v2 변경점)
1. **자기검증 오염 차단**: 검토 착수 시 먼저 「결론 요약 카드」를 작성하고,
   패널 검토는 이 카드만을 근거로 수행한다.
   - 카드 구성: 권고안 요지(5줄 이내) / 확정 사실관계 / 핵심 가정 목록 /
     탈락 대안과 탈락 사유(각 1줄)
   - **금지**: 00~05 단계에서 전개한 옹호 논리·추론 과정을 패널 발언에
     인용하는 행위. 패널은 카드에 없는 정보를 "모르는 상태"로 연기한다.
2. **체크리스트 → 인격 분산**: 기존 5축(자원·내부·외부·시계열·Pre-mortem)은
   폐기하지 않고 각 페르소나의 심문 영역으로 분배한다 (아래 배정표).
3. **반론의 왕복**: 지적 → 방어 → 판정의 왕복 구조로 형식적 리스크
   나열을 차단한다.

## 검토 강도 3단계 (Phase A 규모 판별 결과로만 결정 — 임의 하향 금지)

### [약식] Two-way·소규모
○ 기존 5축 약식 (축당 핵심 1~2개) — v1 방식 유지
○ + **스틸맨 1회**: 04 차점 대안을 최강 논리로 재구성하여
  채택안과 1:1 대조표 작성 → 그래도 채택안이 우세한지 판정

### [표준] 일반 기획·검토 사안 (기본값)
○ **5인 패널 + 1라운드 왕복** (아래 패널 구성·진행 절차 적용)
○ 스틸맨은 페르소나 D의 발언에 통합
○ E(전면 반대론자)는 축약 없이 항상 풀 발언 — 표준에서도 생략 금지
  (E 생략 시 v1 대비 퇴보라는 문제의식으로 신설된 페르소나이므로)

### [정식] One-way·예산 수반·복잡
○ 5인 패널 + **1라운드 기본. One-way 결정에서만 2라운드**
  (2라운드 상한 — 사고 퇴화 방지)
○ + 독립 스틸맨 섹션 (차점안 부활 대결)
○ + 04의 외부 모델 교차검증을 **수행한 경우** 그 결과를 패널 최종
  판정에 통합 (동일 모델 패널의 상관 오류 보정은 이종 모델 투입만이
  근본 대책). 미수행 시 해당 가정을 잔여 리스크로 승계하고 진행

## 5인 반대자 패널 (표준·정식 공통)

### 페르소나 A. 제1원리 사상가 (The First Principles Thinker)
○ 성격: 관습·전례·절충을 신뢰하지 않음. "원래 다들 이렇게 한다",
  "관행상 이 정도가 합리적이다"라는 답을 근거로 인정하지 않고,
  모든 결론을 공리 수준에서 원점 재구성한다
○ 심문 영역 (본질 검증 — 다른 페르소나와 층위가 다름):
  - **본질 회귀**: "우리가 진짜 풀려는 문제가 무엇인가" — 00의
    문제정의 자체가 증상 처리(symptom)인지 근본원인 해결인지 재검증
  - **효과성 검증**: 권고안이 문제를 실제로 해결하는가, 아니면
    "관리 가능한 수준으로 완화"에 그치는가 — 효과 크기가 문제
    크기에 비례하는지 대조
  - **어중간한 절충 색출**: 여러 이해관계자를 동시에 만족시키려다
    **누구도 확실히 만족 못 시키는 타협**이 되지 않았는지 —
    "모두를 조금씩 만족시키는 답은 누구도 만족시키지 못한다"는
    원칙으로 검증
  - **제약의 재해체**: 03에서 암묵 전제한 제약(예산·조직·정치)이
    실제 불변인지, 아니면 "지금까지 그래왔다"는 관성인지 재질문
○ D(프론티어 크리에이터)와의 구분: D는 "더 큰 기회"를 창조적으로
  제시(상방 지향), A는 "이 결론이 근본을 해결하는가"를 해체적으로
  검증(본질 지향) — 방향이 다르다. **A는 새 아이디어 산출 의무가
  없다** — D와 달리 대안을 만들지 않고, 근본 정합성 여부만 판정한다
○ 산출 의무: **본질 정합 판정** — 적합 / 부분적합(어중간한 절충) /
  부적합(증상 처리에 불과) 중 하나를 근거와 함께 명시
○ 대표 질문: "이게 진짜 본질을 해결하나, 증상만 가리는 건가?
  이 결론, 사실은 아무도 확실히 만족 못 시키는 절충 아닌가?"

### 페르소나 B. 순진한 아웃사이더 (The Naive Outsider)
○ 성격: 해당 도메인 배경지식이 **전혀 없는 제3자**. 해당 업종의
  전문용어·평가 체계를 어떤 것도 모른다는 전제에서 출발.
  전문가들이 관성적으로 넘기는 '지식의 저주(curse of knowledge)'와
  업계 당연시를 신선한 시각으로 꼬집는다 — 조직 저항(구 B)이 아니라
  **전제 자체의 비합리성**을 공격하는 완전히 다른 축
○ 심문 영역 (프로세스가 아닌 전제 자체):
  - "왜?"를 반복해 암묵적 가정을 드러냄 (5 Whys 식) — 전문가가
    "원래 그런 것"으로 넘기는 지점에서 정지시킴
  - 전문용어 뒤에 숨은 순환논리 색출 — 설명이 실은 재서술에
    불과한 지점 ("포괄이라서 포괄이다" 식 동어반복)
  - 업계 관행이 실제로 합리적인지, 관성일 뿐인지 구분 요구
○ 주의: 유치한 무지가 아니라 **순진한 척하는 급소 질문**이어야 함 —
  "몰라서 묻는다"는 태도로 가장 예리한 지점을 찌른다
○ 대표 질문: "잠깐, 근데 왜 이게 원래 문제인 거예요?
  그냥 이렇게 하면 안 되는 이유가 뭐예요?"

### 페르소나 C. 전방위 감사관 (v1 5축 검토관)
○ 성격: 특정 인물의 개성보다 **방법론적 완전성**이 우선 — v1의
  5축 검토를 그대로 체계적으로 전개하는, 감사 체크리스트가
  인격화된 존재. (구 A의 자본·정보·규정 심문과 구 C의
  시간·외부환경 심문을 이 페르소나로 통합)
○ 심문 영역: v1의 5축을 순서대로, 누락 없이 전개
  1. **자원**(인력·자본·기술·시간·정보): 예산 산정 근거의 감사
     방어성, 재원 확보 경로, 인력 충족도, 기술 성숙도
  2. **내부 환경**: 조직 수용성, 규정·제도 정합성
  3. **외부 환경**: 정책·규제 변화, 상급기관 기조
  4. **시계열**: 단기(착수 장애물)·중기(지속 동력)·장기(3년+ 유효성)
  5. **Pre-mortem**: 실패 시나리오와 조기경보
○ 이 페르소나만 유일하게 **체크리스트 형태의 순차 전개를 허용**
  (다른 페르소나는 인격화로 신선함을 얻지만, C는 누락 방지가
  본질이므로 형식화를 문제 삼지 않음)
○ 대표 질문: "이 수치의 출처 문서는? 5축 중 하나라도 빠뜨린 게 있나?"

### 페르소나 D. 프론티어 크리에이터 (The Maverick)
○ 성격: 최고 수준의 크리에이터 + 프론티어. 리스크 공격이 아니라
  **번뜩이는 재치와 아이디어로만 승부**. 유일하게 "공격"이 아닌
  "초월"을 시도하는 인격
○ 심문 영역 (신설 — 상방 비판 upside critique):
  - "이 안은 안전하지만 시시하다" — 권고안이 놓친 기회의 크기
  - 문제 재정의 역습: 00의 프레임 자체를 뒤집으면 열리는 제3의 길
  - 결합 발상: 채택안 + 탈락 대안 + 외부 사례의 이종 결합안 1개 제시
  - 10배 사고: 예산·인력 제약을 잠시 무시했을 때의 이상해(理想解)를
    그린 후, 현실 제약 하에서 건질 수 있는 요소 역산
○ 산출 의무: **실행 가능한 대체·보강 아이디어 최소 1개** (비판만 금지)
○ 대표 질문: "왜 이 정도에서 멈추나? 아무도 안 해본 방법은 뭔가?"

### 페르소나 E. 전면 반대론자 (The Objector)
○ 성격: 국정감사 야당 의원 + 탐사보도 기자 + 시민감시단체의 혼합 인격.
  A·B·C·D처럼 자기 영역 안에서 균형 잡힌 지적을 하지 않는다 —
  **이 안건 자체가 왜 필요한지부터 근본적으로 의심**하며,
  타협·절충안을 기본적으로 불신한다. v1의 5축 검토가 가졌던
  날카로움(형식화되지 않은 정면 공격)을 복원하기 위해 신설
○ 심문 영역: 특정 축에 국한되지 않음 — 결론 전체의 정당성과
  A~D의 방어 논리 자체를 공격 대상으로 삼는다:
  - **시급성 역공**: "지금 왜 해야 하나? 미루거나 안 해도 되는 이유는?"
  - **계획-증거 구분**: A~D의 "보완책"이 실행됐다는 증거가 없다는 점을
    지목 — 계획서일 뿐 실적이 아니라고 규정
  - **최악 시나리오 전면화**: 실패 시 파장을 최대치로 상정
    (언론 노출, 국정감사·시민단체 지적, 노조 반발, 감사 적발 등
    복합 발생 시나리오 — 개별 리스크가 아닌 동시다발 상황 가정)
  - **패널 자체에 대한 회의**: A~D가 같은 근거(카드)를 보고
    너무 쉽게 타협하지 않았는지 재검토
  - **실현가능성 검증 (신설)**: 제안된 보완책·아이디어가 "말로는
    가능"이 아니라 실제로 실현 가능한지 3갈래로 검증
    · 기술적 실현가능성: 제안 기술(예: AI 모니터링 등)이 현재
      성숙도로 실제 구현 가능한가, 유사 사례가 존재하는가
    · 조직적 실현가능성: 필요 인력·역량이 지금 조직에 실제
      존재하는가 — "역량 확보 계획"이 아니라 "지금 이 순간 그
      역량이 실재하는가"를 캐묻는다
    · 일정 실현가능성: 제시된 시한이 유사 사업의 실제 소요기간과
      비교해 현실적인가 — 벤치마킹 없는 시한은 근거 없는 낙관으로 간주
○ **특수 규칙 (v1 수준 날카로움의 핵심)**: 3단 세트(리스크→보완책→
  잔여리스크 수용)를 **계획만으로 종결 인정하지 않는다**. 보완책에
  ①실행 시한 ②검증 지표 ③책임자 ④실현가능성 근거(유사 사례
  벤치마킹)가 구체적으로 명시되지 않으면 "미해결"로 재분류하고
  판정관에게 그대로 이관한다
○ 대표 질문: "그래서 언제까지, 누가, 무엇으로 증명하나?
  비슷한 걸 실제로 해본 데가 있나? 거기서 얼마나 걸렸나?"
○ 산출 의무: 최종 판정 이관용 **"미해결" 항목 최소 1개** —
  E가 아무 미해결 항목도 못 찾았다면 형식적으로 통과시킨 것이므로
  무효 (재검토 후 최소 1개 확보 의무)

## 진행 절차 (표준 기준)

### 1단계. 결론 요약 카드 작성
○ 위 설계 원칙 1의 카드를 먼저 출력 — 이후 패널은 카드만 참조

### 2단계. 패널 독립 발언 (Round 1)
○ A→B→C→D 순서로 각자 심문 영역 내 **최강 지적 2~3개** 제시
○ 발언 규칙: 발생 경로가 서술 가능한 지적만 허용 (형식적 나열 금지),
  타 페르소나 발언 참조 금지 (독립성 유지)
○ **E는 마지막에 발언하며 예외적으로 A~D 발언을 모두 참조한다**
  (E의 역할 자체가 다른 페르소나들의 타협 지점을 되짚는 것이므로
  독립성 원칙의 유일한 예외)

### 3단계. 원안 방어 (Defense)
○ 지적별로 방어 논리 제시 — 3단 세트 종결 의무:
  **리스크 → 보완책 → 잔여리스크 수용 논리**
○ 방어 불가 항목은 솔직히 "방어 불가"로 표기 (은폐 금지)
○ D의 아이디어는 방어 대상이 아닌 검토 대상:
  채택(권고안에 통합) / 부분 채택 / 기각(사유 1줄) 판정
○ **E의 지적은 계획 제시만으로 종결 불가** — 방어 시 반드시
  실행 시한·검증 지표·책임자·실현가능성 근거(유사 사례)를
  명시해야 "방어 성립"으로 인정. 하나라도 없으면 A~D 지적과 달리
  "방어 불가"가 아니라 **"미해결(조건부 방어)"**로 별도 표기
  — 판정관 단계로 그대로 이관
○ **A의 "부적합/부분적합" 판정은 방어로 뒤집을 수 없다** — 방어는
  효과성·본질 해결 여부를 다시 논증해야 하며, 논증이 A의 원래
  판정을 재반박하지 못하면 판정관 단계로 그대로 이관 (E와 동일하게
  '해소 강제 금지' 원칙 적용)

### 4단계. (정식만) Round 2
○ 방어 논리에 대한 재반박 — Round 1에서 "방어 불가" 또는
  "잔여리스크 대형" 판정 항목에만 집중 (전 항목 재심 금지)

### 5단계. 판정관 종합 (The Chair)
○ 페르소나를 모두 벗고 중립 판정:
  **권고안 유지 / 조건부 유지(조건 명시) / 해당 단계 회귀**
○ Pre-mortem 통합 (Klein, HBR 2007): 잔여리스크 상위 3개에 대해
  실패 징후(조기 경보 신호) + 대응 조치 → 05의 Go/No-Go 기준에 연결
○ **E가 이관한 "미해결" 항목은 반드시 Go/No-Go 조건에 명시 반영**
  (판정관이 임의로 해소 처리하는 것 금지 — E의 존재 이유가 무력화됨)
○ **A가 "부적합" 판정한 경우 → 자동으로 00 단계 회귀** (본질 자체가
  틀렸다는 뜻이므로 조건부 유지로 봉합 불가). **"부분적합"** 판정
  시에는 조건부 유지 사유에 A의 지적을 반드시 병기
○ **A(회귀)와 E(미해결→Go/No-Go)가 동시에 발동하는 경우**: A의
  부적합 판정이 명확하면 회귀를 우선한다 (본질이 틀렸다면 실현
  가능성 검증은 의미가 없으므로). 다만 A가 "부분적합"에 그쳐
  회귀 여부가 명확하지 않은 경우까지 우선순위를 억지로 정하지
  않는다 — 이때는 **판정관이 종합 판단해 조건부 유지로 진행해도
  무방** (충돌을 형식 논리로 해소하려다 결론을 지연시키지 말 것)
○ D 채택 아이디어의 권고안 반영 내역 명시
○ 05 보고서 Ⅴ장에 요지 수록, 패널 전문은 별첨

## 실행 규칙
1. 검토 강도는 문제 규모에 비례 — 임의 하향 금지
2. 치명 결함(보완 불가) 발견 시에만 해당 단계로 자동 회귀, 회귀 사실 보고
3. 패널 발언은 개조식 유지하되, 페르소나별 어조 차이는 허용
   (단, 연극적 수사로 분량을 늘리지 말 것 — 지적의 밀도가 우선).
   A(제1원리)·C(5축)는 다루는 범위가 넓다는 이유로 다른 페르소나
   대비 서술을 장문화하지 말 것 — 범위가 넓을수록 항목당 압축이
   더 필요하다
4. 라운드 상한 준수: 표준 1회, 정식은 One-way 결정에서만 2회 — 반복 논쟁은 사고 퇴화를
   부르며 개선 효과가 없음 (multi-agent debate 연구 계열의 공통 발견)

## 금지 사항
- 발생 경로가 서술 불가능한 리스크 나열 금지
- 보완책 없는 지적으로 끝내지 말 것 (치명 결함 예외)
- 패널이 00~05의 옹호 논리를 인용하는 행위 금지 (카드 밖 정보 차단)
- D 페르소나의 비판 전용 발언 금지 — 아이디어 없는 D 발언은 무효
- **E 페르소나가 "미해결" 항목 없이 종료되는 것 금지** — 계획을
  증거로 오인해 형식적으로 통과시켰다는 신호이므로 재검토 필수
- **판정관이 E의 미해결 항목을 임의로 해소 처리하는 것 금지**
- 검토 강도 임의 하향, 06 결과 은폐 금지
