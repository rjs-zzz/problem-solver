# Module 04: 평가·의사결정 (Decision Framework)

## 목적
03의 대안들을 동일 기준으로 정량·정성 평가하여 권고안을 확정한다.
평가 과정 자체가 보고서의 설득 논리가 되도록 투명하게 기록한다.

## 주력 방법론
- 가중 평가매트릭스 (Weighted Decision Matrix):
  평가 기준 × 가중치 × 대안별 점수 → 종합
- 가역성 3분류 판별 (베이조스 Door 이론 확장 — Amazon 주주서한, 2015):
  · Two-way (가역): 되돌릴 수 있는 결정 → 신속 결정, 완벽 분석 불요
  · 부분가역: 일부 조치만 회수 가능 → "가역 조치 선행,
    비가역 조치 후행"의 단계적 실행 설계로 연결
  · One-way (비가역): 되돌릴 수 없는 결정 → 신중 분석, 승인 상향

## 예비 방법론
- Pre-mortem (Klein, "Performing a Project Premortem", HBR 2007):
  점수 1·2위 근소차 또는 One-way 결정 시 발동

## 실행 절차
1. **가역성 판별 선행**: Two-way / 부분가역 / One-way 판정 + 근거
   - Two-way: 평가 간소화 (기준 3개 내외, 신속 권고)
   - 부분가역: 정식 평가 + 단계적 실행 순서 설계
   - One-way: 정식 평가 + Pre-mortem + 외부 모델 교차검증 발동
2. **평가 기준 설계**: 문제별 맞춤 기준 4~6개
   - 기본 후보군: 문제해결 효과 / 소요 자원(인력·자본·기술·시간·정보) /
     실행 난이도(승인 경로 포함) / 리스크 / 지속가능성 /
     조직 성과체계·전략 정합성 / 사후 설명 가능성(감사·이사회 대응력)
   - 가중치는 00의 성공 기준에서 도출, 배정 논리 명시
3. **가중치 민감도 검토**: 가중치 ±10~20% 변동 시에도 순위 유지
   여부 확인 — 뒤집히면 '근소차' 판정 (확정 우위처럼 보고 금지)
4. **대안 채점 — 하이브리드 체계 (아래 규칙)**
5. **권고안 확정 + 기각 대안 상세 사유서** (아래 규칙)
6. **결정 요청사항 정리**: 결재권자가 판단해야 할 잔여 쟁점 명시
   — 스킬이 대신 결정하지 않는 영역 구분

## 채점 체계 (하이브리드)
1. **기본 (Two-way / 부분가역)**: 독립 3자 채점
   - 상호 참조 없이 서로 다른 관점의 채점자 3인이 독립 수행
   - 채점자 구성 (문제 성격 따라 조정):
     재무·예산 심사역 / 현장 실무 책임자 / 감사·규정 검토관
   - 통합: 평균 + 편차 표기. 편차 큰 항목(5점 척도 기준 2점 이상)은
     '쟁점' 태깅 후 사유 분석
   - 채점 근거 1줄 필수 (기준×대안 셀마다)
2. **발동 (One-way 또는 쟁점 항목 다수)**: 외부 모델 교차검증
   - **수행 여부는 Phase A에서 사전 확인한다** (실행 중 요청 금지).
     사용자가 수행에 동의한 경우에만 아래 절차를 적용
   - 패키지 생성: 채점용 표준 프롬프트 + 대안 요약 + 평가 기준·가중치
     + Pre-mortem 요청 항목 ("이 안이 1년 후 실패했다면 왜인가" 포함)
   - 권고안 방향이 드러나지 않도록 중립 서술로 작성
   - 사용자가 타 모델에 투입 → 결과 회신 → 스킬이 내부 채점과 통합,
     모델 간 편차 분석 후 최종 판정
   - **미수행 시 (기본값)**: 실행을 멈추지 않는다. 패키지만 부록에
     첨부하고 `[가정] 외부 교차검증 미실시 — 단일 모델 채점의 상관
     오류 보정 없음`을 명시한 뒤 계속 진행. 06 판정관이 이 가정을
     잔여 리스크로 승계
3. **공통 명시**: "본 채점은 판단 보조 도구이며 점수 자체가
   결정 근거가 아님"을 산출물에 표기

## 비용·편익 수치 규칙 (수치 창작 차단 — feasibility-review-loop-p4 분석 모드 준용)
○ 산출 모드는 확보 자료로만 결정하고 의사결정서 1.항에 명시
  - **정밀**: 예산서·견적·실적 등 [1급] 자료 확보 → 금액·B/C 산출
    (산식·분석 기간·출처 병기)
  - **개산**: 부분 자료 → 범위 추정만 허용(점 추정 금지), 전 수치 [추정]
  - **정성**: 자료 없음 → 금액 산출 금지. 비용·편익 항목 식별 +
    등급 판정만 수행, "정밀 산정 별도 필요" 명시
○ 모드 무단 상향 금지 — 자료 없이 금액이 나오면 오류로 간주
○ 채점표의 '소요 자원' 점수는 선택된 모드의 한계 안에서만 부여

## 기각 대안 사유서 (필수)
○ 권고안 확정 후, 기각된 각 대안에 대해 상세 사유 작성:
  - 어떤 기준에서 몇 점 열위였는지
  - 그 열위가 실무적으로 무엇을 의미하는지
  - 어떤 조건이었다면 채택 가능했는지
○ 결재권자가 사유서만 읽고 독자 판단이 가능한 수준으로 작성
  (차선안을 '조건부 선택지'로 제시하지 말고, 미채택 논리를
  투명하게 공개하여 판단을 결재권자에게 귀속)

## 산출물 (개조식)
## 【의사결정서】
### 1. 결정 성격 (Two-way / 부분가역 / One-way 판별 및 근거) + 비용·편익 산출 모드
### 2. 평가 기준 및 가중치 (배정 논리 포함)
### 3. 평가 결과 (3자 독립 채점 통합표: 평균·편차·쟁점, 채점 근거 병기)
### 4. 민감도 검토 결과
### 5. 권고안 및 기각 대안 사유서
### 6. 외부 모델 교차검증 결과 (Phase A에서 수행 합의 시 / 미수행 시 가정 표기)
### 7. 결재권자 판단 요청사항

## 조직 맥락 체크포인트
- One-way 판별 시 조직 특유의 비가역성 반영:
  정원·조직 개편, 다년도 계약, 대외 협약, 인사 발령 등 —
  형식상 가역이어도 행정적·대외적으로 비가역이면 One-way 취급
- 평가 기준에 '사후 설명 가능성(감사·이사회 대응력)' 포함 여부 검토
- 권고안이 상위 계획(중장기 전략, 성과 평가 지표)과 상충 여부 대조

## 금지 사항
- 점수를 권고안에 맞춰 역산 조정하지 말 것 (채점 근거 1줄 의무가 견제)
- 근소차를 확정 우위처럼 보고하지 말 것
- 정치적 수용성을 점수에 몰래 반영하지 말 것 —
  반영하려면 '이해관계자 수용성'을 명시적 기준으로 세울 것
