# 가중 평가매트릭스 템플릿

## 【대안 평가표】

### 1. 평가 기준 및 가중치

| 기준 | 가중치 | 배정 논리 (00 성공 기준 연결) |
|---|---|---|
| 문제해결 효과 | 30% | |
| 소요 자원 (인력·자본·기술·시간·정보) | 25% | |
| 실행 난이도 (승인 경로 포함) | 20% | |
| 리스크 | 15% | |
| 지속가능성 / 감사 방어성 | 10% | |

※ 기준 4~6개, 문제별 맞춤 조정. 가중치 합 100%.

### 2. 독립 3자 채점표 (5점 척도, 채점 근거 1줄 필수)

| 기준 | 대안 A | 대안 B | Do Nothing |
|---|---|---|---|
| 기준1 | 평균 x.x (편차 y) — 근거: | | |
| 기준2 | | | |
| **가중 합계** | | | |

○ 채점자 3인 (상호 참조 없이 독립 수행, 문제 성격 따라 조정):
  - 재무·예산 심사역 관점
  - 현장 실무 책임자 관점
  - 감사·규정 검토관 관점
○ 편차 2점 이상 항목: '쟁점' 태깅 + 사유 분석

### 3. 민감도 검토
○ 가중치 ±10~20% 변동 시 순위 유지 여부: (유지 / 역전 → 근소차 판정)

### 4. 외부 모델 교차검증 패키지 (One-way 또는 쟁점 다수 시)

