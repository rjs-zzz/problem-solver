# Module 02: 진단·분석 (Root Cause Analysis)

## 목적
01에서 배치한 가설(H1, H2...)을 사실·데이터로 검증하여
'진짜 원인'을 확정한다. 검증되지 않은 가설로
대안을 만드는 것을 차단하는 게이트.

## 적용 방식 분기 (문제 성격별)
- **이탈형** (정상→이상): IS/IS-NOT 정식 분석
- **창조형** (신규 기획): 약식 통과 — 제약조건·전제만 검증하고
  비중은 03(대안 도출)으로 이동

## 주력 방법론
- Kepner-Tregoe 문제분석 (Kepner & Tregoe, The Rational Manager, 1965):
  IS / IS-NOT 비교 — 문제가 발생하는 곳 vs 발생하지 않는 곳의
  차이에서 원인 도출
  · WHAT (무엇이 / 무엇은 아닌)
  · WHERE (어디서 / 어디는 아닌)
  · WHEN (언제부터 / 언제는 아닌)
  · EXTENT (어느 정도 / 어느 정도는 아닌)

## 예비 방법론
- First Principles 분해 (머스크): 선례·관행이 원인 규명을 가로막을 때
  "논리적으로 반드시 참인 것"까지 분해 후 재조립.
  "원래 그렇게 해왔다"가 근거로 등장하면 자동 발동

## 실행 절차
1. **가설별 검증 설계**: 각 가설에 대해
   - 참이라면 관찰되어야 할 사실 (예측)
   - 검증에 필요한 데이터·출처
   - 검증 방법 (로컬 자료 대조 / 웹검색 / 사용자 확인)
2. **IS/IS-NOT 분석**: 핵심 가설에 4차원 대조 적용 (이탈형)
3. **데이터 수집·대조**:
   - 근거 위계 준수: [1급] 로컬 자료 최우선 — 자료 요청은
     Phase A에서 완료 (실행 중 추가 업로드 요청 금지)
   - 웹검색 시 근거 등급 표기, 4급 자료 단독 근거 금지
   - 확보 불가 데이터는 임의판단 금지 → [가정 An] 전환 후 진행
4. **미검증 가설 처리 (자동 — 선택지 제시 금지)**:
   - 가정 명시 후 조건부 진행을 기본값으로 자동 적용
   - 가정 목록은 최종 보고서 부록에 필수 첨부
   - 해당 가설이 결론을 좌우하는 경우: 가정별 분기 결론
     (가정 참일 때 / 거짓일 때)을 병기하여 사용자 사후 판단 지원
5. **가설 판정**: 채택 / 기각 / 미검증(보류) 3분류
   - 판정 근거와 출처를 가설별로 명시
   - 정성 근거 인정 기준: 출처 3요소(누가·언제·어떤 맥락)가
     명시된 진술·관찰은 유효 근거로 채택
   - 근거 등급: [정량] > [정성-복수출처] > [정성-단일출처] > [추정]
6. **원인 확정 및 우선순위 갱신**: 01의 (잠정) 라벨을 확정값으로
   갱신, 채택된 원인만 03으로 전달

## 산출물 (개조식)
## 【진단 결과서】
### 1. 가설 검증 총괄
  ○ H1-1. [채택] 근거: ... (등급: [정량], 출처: ...)
  ○ H1-2. [기각] 근거: ...
  ○ H2-1. [미검증] 필요 데이터: ... → 대기 / 조건부 진행 선택 요청
### 2. IS/IS-NOT 분석 (핵심 가설, 이탈형만)
### 3. 확정 원인 및 우선순위 (갱신)
### 4. 조건부 진행 시 가정 목록

## 조직 맥락 체크포인트
- 원인이 규정·제도에 있는 경우: 규정 원문 확인 (추정 금지),
  개정 권한 소재 (내부규정/이사회·경영진/상급기관/법령) 구분
- 원인이 사람·부서에 있는 경우: 개인 귀책 표현 금지,
  구조·프로세스 문제로 환원하여 기술
- 데이터 인용 시 출처·기준시점 명기 (사후 검증·감사 대응력)

## 금지 사항
- 상관관계를 인과관계로 단정하지 말 것
- 미검증 가설을 채택된 것처럼 03으로 넘기지 말 것
- 검증 편의를 위해 가설을 검증 쉬운 방향으로 변형하지 말 것
